# Матрицы комплексных чисел

Лабораторная работа №1 по Java.

## Что делает

Класс для работы с матрицами комплексных чисел:
- Сложение, вычитание, умножение, поэлементное деление
- Транспонирование
- Определитель (1×1, 2×2, 3×3)

Плюс консольный интерфейс для ввода матриц и выбора операции.

## Файлы

- `ComplexNumber.java` — комплексное число
- `ComplexMatrix.java` — матрица комплексных чисел
- `Main.java` — консольный интерфейс

## Как запустить

1. Открыть проект в IntelliJ IDEA
2. Запустить `Main.java`
3. Следовать инструкциям в консоли

## Ограничения

- Определитель — только до 3×3
- Деление — поэлементное (нужны одинаковые размеры, нет нулей в B)
